# HBK example

Artificial data set created by Hawkins, Bradu and Kass (1984). The data set is 
extensively analysed from a Bayesian local influence perspective by Thomas et al (2018).
It is available as the hbk dataset in the R package robustbase (Maechler et al 2024).

This example was removed from the main article to save space. Parts of the paper that
were removed are now in the document HBK.pdf. You can reproduce this from the LaTeX source
which is also included.
