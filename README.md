# bayesian-influence

Supplementary material to accompany the article Bayesian Measures of
Leverage and Influence. The supplementary material allows all the
figures and tables in the article to be reproduced, and also includes
some additional figures not shown in the article.

There are 5 examples

- abalone. Marine survey data used to to illustrate the detection of anomalous observations (high leverage, high influence, and outliers).
- bikesharing. Capital Bikeshare data used to illustrate outliers.
- UNOS. United Network for Organ Sharing data used to illustrate prior-data conflict.
- BRI. Bristol Royal Infirmary inquiry data used to illustrate cross-conflict in a hierarchical model.
- HBK. An artificial dataset. This example was cut from the paper for space reasons.

The examples all use R and JAGS 5.0.0.
