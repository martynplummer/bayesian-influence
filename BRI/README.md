# Bristol Royal Infirmary data 

Measuring cross-conflict using the pV/pW ratio.

## Inputs

* `BRIdata.csv` Data from Marshall and Spiegelhalter (2007) in CSV format.
* `bri.bug` Random-effects logistic regression model.
* `bri.R` Reproduce figure 5 from the article (`bri-figure.pdf`).

## Outputs

* `bri-figure.pdf` Figure 5.
